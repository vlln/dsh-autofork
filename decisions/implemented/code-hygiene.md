# 代码卫生清理与验证边界

分类：simplification / bug-fix / testing

## Problem

连续增量修改留下未引用变量、无调用包装函数、过时注释和重复读取。部分测试仅证明桩的行为：徽标“幂等”测试重建了插件，DOM remove 没有移除父子关系；恢复失败测试创建了无关现场。存储关闭与异步打开、刷新、写入缺少协调，未命名边实际写 ordinal=0 却被 schema 拒绝。

## Decision

- 删除确认无引用的客户端局部变量、常量、空 disposer 和宿主 senderPrefixed；保留默认关闭但仍受支持的容器功能。
- 血缘存储协调 ready、refresh、put 与 close，关闭后不再重开；存储子插件清理自身句柄，不关闭后续挂载的句柄。
- 会话设置合并保留较新的本地记录；同进程更新时间戳单调。ordinal schema 允许写入端约定的 0。
- 侧栏徽标在禁用、记录删除、行复用及卸载时清理；使用同一实例轮询及真实父子关系桩验证幂等。
- 自动回注开关的 aria-checked 表达开启状态；自绘 hover 面板复用 live 判据；血缘高亮遍历防止循环。
- 门禁读取 manifest 声明的客户端入口作为唯一来源，并增加负控测试；语法检查覆盖 refresh 模块。
- 修复 README 断裂表格、过期名称/状态/唤醒说明及已归档管理入口。工程笔记不再把设计上的降级目标写成无条件安全保证。

## Alternatives considered

- 大规模拆分入口或引入新构建/lint 依赖：会扩大验证面；本轮优先处理有调用与测试证据的问题。
- 删除默认关闭的容器路径：属于产品能力移除，不是死代码清理，本轮不做。
- 只删除文本和变量、不补测试：无法防止同类生命周期与桩失真问题再次出现。

## Consequences

包版本不变，不发布、不推送；工作区保留供审阅。完整 `npm run verify` 为 180 项通过，0 失败、0 跳过，`git diff --check` 通过。

本轮未重启用户 GUI，也未完成真实宿主装载或浏览器视觉回归；静态 React 桩不能证明真实 effect、重渲染或事件冒泡。

剩余边界：跨进程序号 max+1 无原子锁；设置更新时间戳不能仲裁跨进程时钟偏差；agents.resume 的所有权关联调用上下文，插件卸载后的会话生命周期需真实宿主验证；DOM 集成仍依赖非公开结构。
